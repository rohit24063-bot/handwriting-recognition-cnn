# Handwritten Character Recognition (CNN + LSTM)

## Overview
This project builds a deep learning model to recognize handwritten characters using TensorFlow.

## Features
- CNN + LSTM architecture
- Data preprocessing and normalization
- Early stopping and learning rate scheduling
- Real-time prediction function

## Results
- Test Accuracy: 89.6%
